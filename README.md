# 活塞智研 · GitHub Pages 发布分支

渤海活塞 × 深势科技的活塞企业 AI 应用场景演示。

## 文件与来源

- `index.html`：网页入口与双品牌演示标识。
- `style.css`：自适应界面样式。
- `app.js`：场景问答、工艺参数优化、样例数据、报告导出。
- `.nojekyll`：直接发布静态文件。

本分支是 `piston-ai-demo` 分支 `docs/` 目录的发布副本。网站文件放置在根目录，不依赖构建工具、在线 API 或密钥。原仓库 `main` 分支与研究代码保持不变。
